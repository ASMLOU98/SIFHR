# SIFHR | AI-Powered 3D Educational Game

**An immersive educational experience inspired by Arabo-Muslim civilizations, combining Artificial Intelligence, conversational AI and 3D technologies.**

## 🇫🇷 Présentation

SIFHR est un jeu éducatif intelligent en 3D qui valorise le patrimoine scientifique et culturel arabo-musulman à travers des interactions immersives avec des personnages virtuels et un assistant conversationnel basé sur l'IA.

**Fonctionnalités :**
- Environnement interactif en 3D.
- Assistant conversationnel intelligent (LLM).
- Génération de réponses contextuelles.
- Synthèse vocale (Text-to-Speech).

## 🇬🇧 Overview

SIFHR is an intelligent 3D educational game promoting Arabo-Muslim scientific and cultural heritage through immersive interactions with virtual characters and an AI-powered conversational assistant.

**Key Features:**
- Interactive 3D environment.
- LLM-powered conversational assistant.
- Context-aware AI responses.
- Text-to-Speech integration.

## 🛠️ Tech Stack

React.js · Node.js · Express.js · Python · Flask · LLaMA 3.1 8B · Groq API · LangChain · PostgreSQL · Unity · WebGL
